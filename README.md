# Paper Pilot

A tool for reading and analyzing research papers.

## Structure

```
.
├── src/
│   ├── paper.py        # Paper data model
│   ├── pdf_reader.py   # PDF text extraction
│   ├── analyzer.py     # Paper analysis
│   └── storage.py      # Load/save results
├── data/               # Input PDFs and source data
├── outputs/            # Generated analysis output
├── tests/              # Test suite
├── main.py             # Entry point
├── requirements.txt    # Python dependencies
└── README.md
```

## Usage

```bash
python main.py
```
